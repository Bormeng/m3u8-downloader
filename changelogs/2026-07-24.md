# 2026-07-24

## 新增:内嵌浏览器支持 iPad UA 切换

### 背景
很多视频站点桌面版的 player 套了好几层壳(video.js / shaka / 自研 DRM
包装),JSExtractor 不一定抓得到 m3u8 源,而且部分站点对桌面 UA 直接 403
或返回不一样的页面。换成 iPad Safari UA 后,服务端倾向于返回平板版
HTML5 player,通常更直白、m3u8 source 更容易在 video element / hls.js
实例里露出来。

### 改动
- `BrowserViewModel.swift`:
  - 新增 `static let iPadUserAgent: String` —— 标准 iPad Safari 17 UA
    (`Mozilla/5.0 (iPad; CPU OS 17_0 like Mac OS X) AppleWebKit/605.1.15
    (KHTML, like Gecko) Version/17.0 Mobile/15E148 Safari/604.1`)
  - 新增 `@Published var useIPadUA: Bool`,UserDefaults key
    `m3u8dl.useIPadUA` 持久化,默认 `false`(保持现有桌面行为)
  - 新增 `func setUseIPadUA(_:)` —— flip flag + 同步更新现有
    `WKWebView.customUserAgent` + `wv.reload()` 当前页。`didSet` 写
    UserDefaults,setter 里 `guard enabled != useIPadUA else { return }`
    避免无效重复 reload
- `WebBrowserView.makeNSView` 在创建 WKWebView 时读
  `vm.useIPadUA`,设 `wv.customUserAgent = iPadUA : nil`(nil 走
  默认 macOS Safari UA)
- `BrowserView` 导航栏右侧(loading indicator 之后)加切换按钮:
  - iPad 模式:`Image(systemName: "ipad")`,`foregroundStyle = .accentColor`
  - 桌面模式:`Image(systemName: "desktopcomputer")`,`foregroundStyle = .secondary`
  - tooltip:`"当前:iPad UA(点击切回桌面)"` / `"当前:桌面 UA(点击切到 iPad)"`
  - 点击 → `vm.setUseIPadUA(!vm.useIPadUA)`,自动 reload 当前页

### 影响范围
- iPadOS 13+ 在真机上会"伪装 Mac"避免被推桌面版,但 macOS 上 WKWebView
  不会做这个伪装 —— 我们手动设什么 UA,服务端就看到什么。普通的
  `iPad; CPU OS 17_0 like Mac OS X` 字串就够触发 iPad 路径
- HLS 探针 / N_m3u8DL-RE 都不受此影响 —— 只动内嵌浏览器请求的 UA
- 不会动 `HTMLDiscoverer.swift` 里给直连 m3u8 URL 设的默认 Chrome UA
  (那是给"从 HTMLDiscoverer 抓到的链接"用,跟浏览器渲染无关)
- 没动 PlayerViewModel / DownloaderViewModel / ProcessRunner

### 副作用 / 已知保留
- 切完等页面 reload 完成才看到效果(几百 ms),不是即时
- 不影响 WKWebView 已经在内存里持有的资源(cached 资源可能还是用老 UA
  抓的);如果发现切完页面没区别,先 ⌘R 或点 Stop 再访问一次清缓存
- 状态只持久化 `useIPadUA` 一个 bool;没存"每个站点单独记忆 UA"
  这种高级功能,个人项目用不上
- 没在 Settings 场景里再加一个开关 —— 导航栏已经够顺手,场景里
  重复一遍反而干扰

### 调整:iPad UA 改为默认
用户偏好 iPad UA 作为默认(理由同上,iPad 布局对抓 m3u8 更友好)。
只影响"还没手动存过值"的新装机用户 —— 已经在导航栏里手动选过桌面
UA 的人,`m3u8dl.useIPadUA` key 存的是 `false`,启动时读 UserDefaults
的逻辑保留他们的选择;没存过 key 的人(也就是这条 commit 之前
的所有用户,包括这次新装的)启动时拿到 iPad UA。

实现:`useIPadUA` 的初始化闭包在 `defaults.object(forKey: ...) == nil`
时返回 `true` 而不是 `false`;doc comment 同步更新说明。
