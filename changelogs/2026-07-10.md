# 2026-07-10

## 优化:播放工具栏三点改进(合并跨度 / 前进后退按钮 / 音量控制)

### 背景
原 settings toolbar 把前进和后退的跨度拆成两个独立的数字输入框,占地方又
重复;控件区只有 play/pause + 进度条 + 时间,没法直接控制音量,用户要看
视频只能去系统菜单栏调 —— 体验割裂。三处都小,但每天播放都会碰到。

### 改动
1. **跨度输入合并**:前进和后退共用一个 "跨度" 输入框,都从同一个
   `PlayerViewModel.skipSeconds` 读取/写入。视频双击左右半屏也共用这个值。
2. **前进 / 后退按钮**:settings toolbar 里新加 ⏪ / ⏩ 按钮
   (`gobackward` / `goforward` SF Symbol),夹在跨度输入框两侧组成
   `[⏪] [跨度 N s] [⏩]` 视觉单元,触发 `skipBackward()` / `skipForward()`。
   视频双击左右半屏手势保留。控件区回到只有 ▶ / 进度条 / 时间。
3. **音量控制**:settings toolbar 右侧追加音量 cell = 静音按钮 + 音量 slider。
   - 静音按钮图标根据 `volume + isMuted` 在 `speaker.slash` /
     `speaker.wave.1/2/3` 之间切换(0 / 静音 → slash,跟 macOS 系统音量菜单一致)
   - `volume`(0.0 ~ 1.0)和 `isMuted` 互相独立,持久化
   - 拖动 slider 只改 volume,需要静音点 🔇 —— 跟 QuickTime / IINA 一致
   - 真实可听音量 = volume × !isMuted,通过 `AVPlayer.volume` / `AVPlayer.isMuted`
     双重应用,新 play() 加载视频时也立刻套上持久化的值

### 影响范围
- `PlayerViewModel`:
  - 删 `skipForwardSeconds` / `skipBackwardSeconds`,合并为 `skipSeconds`
  - 删 `setSkipForward` / `setSkipBackward`,新增 `setSkipSeconds`
  - 新增 `volume: Float` / `isMuted: Bool` 状态 + `setVolume` / `setMuted`
  - UserDefaults key 变化:`skipForwardKey` / `skipBackwardKey` →
    `skipSecondsKey`;新增 `volumeKey` (`player.volume`) / `mutedKey` (`player.muted`)
  - `play(url:...)` 末尾 `newPlayer.volume = volume; newPlayer.isMuted = isMuted`
- `PlayerView`:
  - `settingsToolbar` 把 ⏪ / ⏩ 按钮 + 跨度输入框组合成 `skipControl`
    (嵌套 HStack,内部间距 4pt),跟外层 HStack 的 12pt 大间距区分开
  - `controls` 恢复为只有 play/pause + 时间 + 进度条 + 时间
  - 速度 slider 保留 `.frame(maxWidth: .infinity)` 占满剩余宽度,跨度和音量
    按自然宽度排在右侧(去掉 `skipField` 内部的 `frame(maxWidth: .infinity)`,
    否则会把速度挤到 1/3)
- 占位提示文字保留(双击手势仍然有效,跟工具栏按钮走同一 `skipSeconds`)

### 副作用 / 已知保留
- 老 UserDefaults key(`player.skipForwardSeconds` / `player.skipBackwardSeconds`)
  不迁移,本机存量的会被忽略,新值用新 key 写。个人项目,懒得写迁移
- 拖动音量 slider 不会自动取消静音(和 macOS 系统级媒体控件一致)
- 第一次启动 `volume` 默认 1.0、`isMuted` 默认 false
- 双击视频 + 工具栏按钮并存,行为用同一 `skipSeconds` 驱动,不会不一致
